================================================================================
1. ОБЗОР
================================================================================

Жанр:      2D дуэльный арена-шутер (Casual Arena)
Платформа: Web (Unity 2022.3.62f2, WebGL), публикация — Yandex Games
ФОРМАТ:    9:16 ПОРТРЕТ — только. Дуэль вертикальная: игрок и враг
           спавнятся ВВЕРХУ/ВНИЗУ арены. Ширина арены = узкая сторона.
Стиль:     Мультяшный 2D, сочные эффекты
Физика:    Встроенная физика НЕ используется. Гравитации нет. Движение —
           кинематическое, кастомный код импульсов/инерции.
Языки:     RU, EN, TR (авто по локали Яндекса + ручной выбор в настройках)
Сессия:    Бесконечная цепочка дуэлей 1-на-1, ~30–60 сек на бой

Питч:
  Ты — пистолет в невесомости. Единственный способ двигаться — стрелять.
  Каждый выстрел отталкивает тебя, каждую пулю можно парировать или взорвать
  другой пулей. Побеждай врагов, зарабатывай деньги, покупай новое оружие
  и поднимайся по бесконечной лестнице дуэлей.

Философия: «просто, но со вкусом» — простые правила, глубина через
  скилл (парирование, отдача-движение), максимум сочности эффектов.


================================================================================
2. ОСНОВНОЙ ЦИКЛ
================================================================================

  Дуэль 1v1 → победа → деньги + следующий уровень (враг сложнее)
                    ↘ поражение → БЕЗ денег, следующий уровень
                                 + предложение возрождения за рекламу

  Магазин: главное меню + экран победы (см. 5).
  На переходах уровней — interstitial-реклама (см. раздел 5).

  Проиграть забег нельзя — уровни бесконечны. Деньги зарабатываются
  только победами. Смерть не заканчивает игру, а наказывает экономикой
  и предлагает rewarded-рекламу.


================================================================================
3. УПРАВЛЕНИЕ / ВХОД
================================================================================

  - Только мышь / сенсор (единая логика: курсор или касание экрана).
  - Наведение — пистолет целится в точку курсора/касания.
  - КОНСТАНТА ВХОДА: нажатие = ВЫСТРЕЛ. Всегда, при любых обстоятельствах,
    когда стрельба возможна (есть патрон, нет полной перезарядки, не
    грейс-период старта). См. 4.5 — исключений нет.
  - ПАРИРОВАНИЕ — тайминг-слой ПОВЕРХ того же нажатия: не отменяет,
    не заменяет и не откладывает выстрел (см. 4.5).
  - Клавиатура не нужна — важно для веба и мобильных устройств.


================================================================================
4. КЛЮЧЕВЫЕ МЕХАНИКИ
================================================================================

4.1. ДВИЖЕНИЕ = ОТДАЧА
  - Гравитации нет. Игрок дрейфует по инерции, отскакивает от стен арены.
  - Выстрел придаёт импульс в противоположную сторону и визуально
    «опрокидывает» оружие.
  - Движения без стрельбы не существует: игрок управляет позицией
    только выстрелами — ядро геймплея.

4.2. СТАРТ РАУНДА
  - Игрок и враг спавнятся на ПРОТИВОПОЛОЖНЫХ КОНЦАХ вертикальной арены
    (низ / верх), враг — с зеркальной ориентацией.
  - Оба получают случайный импульс движения и вращения —
    раунд начинается в дрейфе.
  - ГРЕЙС-ПЕРИОД ~1с (в конфиге): после спавна стрельба заблокирована
    ОБЕИМ сторонам, идёт стартовый дрейф. Решает «смерть в первые
    полсекунды» от мгновенной реакции ИИ при случайном спавн-импульсе.

4.3. БОЕЗАПАС
  - У оружия есть магазин. После выстрела патроны РЕГЕНЕРИРУЮТ со временем
    по одному.
  - Если потрачен ВЕСЬ магазин — полная перезарядка (заметно дольше регена) —
    наказание за спам.
  - У каждого оружия своё КД между выстрелами.
  - Во время полной перезарядки нажатия НЕ делают ничего: ни выстрела,
    ни парирования (парри привязан к выстрелу, см. 4.5).

  4.3.1. ТИПЫ СТРЕЛЬБЫ (КАНОН MVP)
  Основа: все оружия стреляют по сути одинаково — разница в КД и паттерне.

  | Паттерн           | Поведение                                   | Отдача                  | Боезапас                                    |
  |-------------------|---------------------------------------------|-------------------------|---------------------------------------------|
  | Одиночный (пист.) | тап = 1 пуля, большое КД (~0.8с)            | сильный одиночный толчок | эталон                                      |
  | Очередь (M16)     | тап = фиксированная очередь 3 пули, НЕ пре-  | 3 средних толчка        | патроны списываются по пулям                |
  |                   | рывается, затем КД очереди; одиночный тап   |                         |                                             |
  |                   | всегда = полная очередь                     |                         |                                             |
  | Зажим (автомат)   | пока зажата ЛКМ / палец на экране — стреляет| много мелких толчков =  | быстрый слив магазина → наказание спама     |
  |                   |                                             | плавное руление дрейфом |                                             |
  | Дробь (дробовик)  | 1 тап = 5–7 дробинок веером                 | МОЩНЕЙШИЙ толчок —      | много патронов за один выстрел              |
  |                   |                                             | инструмент перемещения  |                                             |

  Правила очереди (M16):
    - патроны списываются по пулям очереди;
    - реген идёт НЕПРЕРЫВНО (успевает добавить 0–1 патрон между пулями —
      на геймплей не влияет, отдельно не блокируем);
    - опустошение магазина посреди очереди → очередь обрывается +
      стартует полная перезарядка (единое наказание за спам).

  Отдача по паттернам — ориентиры в конфиге (дробь толкает сильнее всех,
  автомат — множество мелких импульсов).

  Выдача врагам (ориентир): ур. 1–5 пистолет → 5+ очередь → 10+ дробь →
  дальше смеси.

4.4. ПУЛИ
  - Пули — быстрые проджектайлы (не хитскан).
  - Скорость пули к скорости дрейфа игрока ≈ 13:1 (настраивается в конфиге):
    и не слишком сложно, и скорость чувствуется. Ориентир: пуля пересекает
    арену (по высоте) примерно за 0.3–0.4с.
  - Полёт пули у каждого оружия свой (скорость/траектория) — часть идентичности
    оружия (см. 4.4.2).
  - ПУЛЯ В ПУЛЮ → ВЗРЫВ (см. 4.4.1).
  - Пуля, не попавшая ни во что:
      * обычная пуля — исчезает при попадании в стену ИЛИ ПРЕПЯТСТВИЕ
        (колонны гасят пули так же, как стены);
      * ПАРИРОВАННАЯ пуля — рикошетит от стен И ПРЕПЯТСТВИЙ 2–3 раза
        с бешеной скоростью, носится по арене как в концепте; после
        исчерпания отскоков (общий счётчик для стен и препятствий)
        исчезает.

  4.4.1. ВЗРЫВ ПУЛЯ-В-ПУЛЮ (ключевая механика)
    - Радиус: ~15% ширины арены (портрет: ширина = узкая сторона) (в конфиге).
    - Урон: числовой, равен урону оружия-владельца пули (ориентир 1.0,
      см. 4.7). В конфиге.
    - Взрыв бьёт ОБЕ стороны — и игрока, и врага: честный риск для обоих.
      (Исключение — бафф AoE, он НЕ взрыв: см. 4.9.)

  4.4.2. ТРАЕКТОРИИ ПУЛЬ (КАНОН MVP)
    | Траектория   | Параметры в конфиге              | Примечание                          |
    |--------------|----------------------------------|-------------------------------------|
    | Прямая       | скорость (база 13:1)             | эталон читаемости                   |
    | Синусоида    | амплитуда, частота, скорость     | пуля медленнее базы (~0.6с на арену), иначе нечитаемо |
    | Гоминг       | радиус захвата, сила поворота,   | цель всегда одна (игрок 1v1): для   |
    |              | скорость                         | пуль игрока — враг, для вражеских — |
    |              |                                  | игрок. ПЕРИХВАТЫВАЕТСЯ чужими пу-   |
    |              |                                  | лями как обычная — это контригра.   |
    |              |                                  | Парированная гоминг-пуля меняет    |
    |              |                                  | цель на стрелка.                    |
    | Разгоняющаяся| стартовая скорость, ускорение    | синергия с отдачей: выстрелил-      |
    |              |                                  | улетел, пуля догоняет               |

    СПИРАЛЬ — исключена из MVP: нечитаема на маленькой арене при 13:1.

4.5. ПАРИРОВАНИЕ (постоянная механика)
  - Доступно всегда, без рандома. Привязано к выстрелу: парри существует
    ТОЛЬКО как тайминг-слой поверх нажатия-выстрела.
  - КОНСТАНТА: нажал = выстрел. Выстрел происходит ВСЕГДА, когда возможен
    (патрон есть, перезарядки нет, не грейс-период). Парирование ничего
    не отменяет: при успехе игрок и отбил пулю, и выстрелил (патрон
    потрачен, отдача отработала) — парри НЕ бесплатный.
  - ДЕТЕКЦИЯ (технически): БУФЕР ВВОДА.
      1. Нажатие открывает окно тайминга 200мс (в конфиге).
      2. Если за это окно вражеская пуля ВОШЛА в зону парирования
         (радиус вокруг игрока, в конфиге) → УСПЕХ: пуля парирована.
      3. Окно закрывается по истечении 200мс или по успешному парри.
  - Провал (нажал слишком рано/поздно): выстрел всё равно произошёл
    (он происходит всегда); не увернулся физически — получаешь урон,
    плюс тебя толкает отдача собственного выстрела. Риск/награда.
  - Успех: пуля отправляется обратно с резко увеличенной скоростью,
    получает 2–3 рикошета от стен/препятствий (см. 4.4), летит во врага /
    носится по арене. Гоминг-пуля меняет цель на стрелка.
  - Анти-дабл-парри: после успешного парирования минимальный КД ~100мс
    (в конфиге) — одна пуля не парируется дважды одним нажатием.
  - Пустой магазин / полная перезарядка: нажатие не делает НИЧЕГО —
    ни выстрела, ни буфера парирования. Наказание за спам остаётся
    осмысленным.
  - Рычаги баланса (плейтест): длина окна, радиус зоны, КД анти-дабл-парри.

4.6. ИГРОК
  - Выдерживает 3 попадания. Под капотом — числовое HP (3.0), урон
    наносится по числам оружия (см. 4.7).
  - I-FRAMES: ~0.6с неуязвимости после получения урона (в конфиге),
    визуально — мерцание спрайта. Спасает от shred-а автоматом/дробью
    врага. Блокирует и взрывы.
  - Внешнего HP-бара нет — обратная связь через визуал и эффекты
    (тряска, звук, повреждение спрайта, мерцание i-frames).

4.7. ВРАГ
  - Враг — тоже оружие-персонаж (другие скины/модели).
  - HP врага — ЧИСЛОВОЕ под капотом, поделено на 3 СТАДИИ:
      * каждая стадия — свой запас HP (например: 5.0 / 4.0 / 3.0,
        настраивается в конфиге);
      * урон накапливается внутри стадии; при обнулении — переход
        на следующую стадию;
      * каждая стадия — свой спрайт (постепенное разрушение);
      * при смене стадии — звук разрушения + эффект;
      * на последней стадии враг выдерживает всего несколько попаданий.
  - Оружия наносят РАЗНЫЙ урон (числа в конфиге, ориентиры):
      пуля пистолета 1.0, дробинка ~0.3, взрыв 1.0 и т.д.
  - Визуально для игрока всё как было: «попадания и стадии», числа
    скрыты под капотом.

4.8. ИИ ВРАГА И СКАЛИРОВАНИЕ СЛОЖНОСТИ
  - Враг стреляет со случайным КД (рандомные интервалы).
  - Поле зрения: КОНУС по направлению оружия врага (угол в конфиге,
    ориентир 90–120°), ПРОВЕРЯЕТСЯ LOS — препятствия блокируют обзор.
    Если игрок в конусе и на линии видимости — враг стреляет СРАЗУ.
  - С ростом уровня:
      * уменьшается КД между выстрелами;
      * повышается скорость реакции;
      * меняются паттерны стрельбы (см. 4.3.1 — выдача врагам).
  - Пули врагов — такие же проджектайлы, летят достаточно быстро.
  - ЭЛИТА: каждые 10 уровней (в конфиге) — элитный враг:
      * уникальный скин;
      * HP каждой стадии ×2 (в конфиге);
      * быстрее КД между выстрелами;
      * громкая подача: спец-звук на старте боя, особая рамка уровня.

4.9. БАФФЫ
  - Спавнятся как ДРЕЙФУЮЩИЕ по арене предметы-капсулы, подбор касанием.
  - ВРАГ ИГНОРИРУЕТ КАПСУЛЫ: баффы — только ресурс игрока.
  - Частота спавна: рандомное время или фиксированный интервал —
    НАСТРАИВАЕТСЯ В КОНФИГЕ (MVP).
  - Список баффов:
      1. Замедление времени для игрока (слоу-мо, враг замедлен).
      2. Ускоренная перезарядка на несколько секунд.
      3. AoE-всплеск на всю арену: бьёт ТОЛЬКО врага (сквозь
         препятствия), урон 1.0 (в конфиге). Это награда за подбор,
         НЕ взрыв пуля-в-пулю — игрока не задевает. (Взрывы пули-в-пулю
         при этом по-прежнему бьют обоих — см. 4.4.1.)
      4. «МИНИГАН»: несколько секунд оружие игрока стреляет само,
         БЕЗ управления игроком и БЕЗ траты патронов; направления
         хаотичны (рандомный сектор); отдача работает ПОЛНОСТЬЮ —
         игрок дико летает по арене от отдачи. ХАОС И ХАОС.


================================================================================
5. ПРОГРЕССИЯ И ЭКОНОМИКА
================================================================================

  - Деньги начисляются ЗА ПОБЕДУ в дуэли.
  - Кривая (настраивается в конфиге): «среднее между быстрым стартом
    и казуалом» — денег много, награда ощутимая; цены растут немного,
    но заметно:
      * награда растёт с уровнем (например 25 + уровень×2);
      * первая покупка доступно быстро (первые победы первой сессии);
      * каждое следующее оружие/апгрейд дороже предыдущего на умеренный
        коэффициент (заметно, но не гриндово).

  ЭКИПИРОВКА:
  - Оружие ОДНО НА СЕССИЮ. В бою переключения нет.
  - Стартовый пистолет — бесплатный, навсегда.
  - Смена оружия — только вне боя через магазин (см. 8): купленное/
    выбранное оружие экипируется на СЛЕДУЮЩУЮ дуэль.

  МАГАЗИН (доступен из главного меню И с экрана победы):
  - ВКЛАДКА «ОРУЖИЕ»: типы стрельбы по канону 4.3.1, траектории по
    канону 4.4.2. Оружие = сайдгрейды: разная манера стрельбы, полёт
    пули и сила отдачи. Покупка → экипировка на следующий бой.
  - ВКЛАДКА «СКИЛЛЫ» (ПЕРКИ): ГЛОБАЛЬНЫЕ перманентные улучшения, действуют
    на ВСЁ оружие сразу. Применяются СРАЗУ после покупки (в т.ч. купленные
    с экрана победы — действуют в следующем бою).
      Список перков MVP (по разному влияют, см. правило ниже):
        * КД между выстрелами — −X% за ранг;
        * Ёмкость магазина — +X% за ранг;
        * Реген патронов / полная перезарядка — −X% времени за ранг;
        * Урон — +X% к числовому урону за ранг;
        * Сила отдачи — +X% за ранг (манёвренность движением).
      ПРАВИЛО ИДЕНТИЧНОСТИ (ключевое): у каждого перка — ранги (ориентир
      5) и КАП суммарного эффекта (ориентир КД −30% максимум, значения
      в конфиге). Капы подобраны так, чтобы archetype оружия НЕ ломался:
      максимальная вкачка КД у ПИСТОЛЕТА не превращает его в пулемёт —
      «одиночный с большим КД» остаётся одиночным, автомат всё равно
      стреляет чаще, дробовик остаётся мощным разовым толчком. Перки
      УСИЛИВАЮТ стиль оружия, но НЕ меняют его суть.
  - ВКЛАДКА «СКИНЫ»: визуальная кастомизация оружия (монетизация/косметика).

  ПОРАЖЕНИЕ:
  - Игрок отправляется на следующий уровень к другому врагу, БЕЗ денег.
  - При смерти показывается меню: просмотр рекламы (rewarded) за
    ВОЗРОЖДЕНИЕ:
      * это НЕ рестарт уровня — бой продолжается на том же уровне;
      * полное восстановление всех показателей ИГРОКА (3 хита, патроны);
      * бонус: несколько секунд ускоренной перезарядки.
  - КАП ВОЗРОЖДЕНИЙ: 1 (один) за бой. После второй смерти в том же бою
    предложение рекламы НЕ показывается — только «продолжить без
    награды».

  РЕКЛАМА (Yandex Games SDK):
  - Rewarded: возрождение (см. выше).
  - INTERSTITIAL: показывается на переходах уровней (после экрана победы
    «Дальше» / после поражения «Продолжить без награды»). Не чаще одного
    раза в N секунд (интервал в конфиге, ориентир 60с) — защита от спама
    на быстрых поражениях.

  ЛИДЕРБОРД (Yandex leaderboard по максимальному достигнутому уровню):
  ПОСЛЕ РЕЛИЗА, не в MVP.

6. КАРТЫ
================================================================================

  - Бой происходит в небольшой «коробке» — замкнутой ВЕРТИКАЛЬНОЙ арене
    (формат 9:16).
  - Пул из 5–6 ручных карт, у каждой своя фишка:
      * шире/уже или выше стандартной;
      * препятствия/колонны;
      * упор больше во врагов (минимум препятствий).
  - РОТАЦИЯ: случайная карта из пула, БЕЗ повтора той же карты два раза
    подряд.
  - Карты собираются ВРУЧНУЮ (разработчиком), генератор карт НЕ требуется.
  - Формат карты (что задаёт карта): размер арены, препятствия и их форма,
    точки спавна игрока и врага, зоны спавна баффов.

7. ЭФФЕКТЫ, ЗВУК, «СОЧНОСТЬ» (JUICE)
================================================================================

  ВИЗУАЛ:
  - При выстреле: вспышка света, партиклы, шейк камеры, флип оружия.
  - При попадании по врагу: шейк/эффект камеры, звук.
  - Смена стадии врага: звук разрушения + партиклы обломков.

  - Успешное парирование: слоу-мо-вспышка, звуковой акцент.
  - I-frames игрока: мерцание спрайта.
  - Элита: особая подача (рамка уровня, спец-звук старта).

  АУДИО-СКОП (MVP):
  - 1 бодрый фоновый трек на всю игру.
  - SFX-сет: выстрелы по паттернам (пистолет/очередь/автомат/дробь),
    попадание по игроку/врагу, смена стадии врага, взрыв пуля-в-пулю,
    парирование (успех/промах), подбор баффа, эффекты баффов

9. КОНФИГУРИРУЕМЫЕ ДАННЫЕ (всё через конфиги, не хардкод)
================================================================================

  - Оружие: урон (числа: пуля 1.0, дробинка ~0.3 и т.д.), КД, размер
    магазина, скорость регена, время полной перезарядки, скорость/
    поведение пули, тип стрельбы (4.3.1), сила отдачи.
  - Парирование: окно буфера (200мс), радиус зоны парирования, КД
    анти-дабл-парри (~100мс).
  - Скорости: скорость пуль и скорость дрейфа (соотношение ~13:1),
    скорость парированной пули, число рикошетов (2–3).
  - Траектории: амплитуда/частота синусоиды, радиус захвата и сила
    поворота гоминга, стартовая скорость и ускорение разгоняющейся.
  - Взрыв: радиус (~15% ширины арены), урон (= урону оружия).
  - Игрок: HP (3.0), i-frames (~0.6с), импульс отдачи, отскок от стен.
  - Враг: HP каждой из 3 стадий, базовое КД, скорость реакции,
    угол конуса зрения, параметры скалирования от номера уровня,
    таблица выдачи паттернов по уровням.
  - Элита: каждый N-й уровень (10), множитель HP стадий (×2),
    множитель КД.
  - Старт раунда: длительность грейс-периода (~1с), диапазон случайного
    спавн-импульса.
  - Баффы: длительность/сила каждого, интервал или рандом спавна,
    параметры минигана (длительность, скорострельность, сектор спрея),
    урон AoE.
  - Экономика: награда за победу, цены оружия/скиллов/скинов,
    коэффициент роста цен.
  - Перки: список перков, число рангов, значения за ранг, растущая цена
    рангов, КАП суммарного эффекта на каждый перк (правило идентичности).
  - Реклама: интервал между interstitial (ориентир 60с), кап возрождений.
  - Карты: пул карт, правило «без повтора подряд».

10. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ / АРХИТЕКТУРА
================================================================================

  - Unity 2022.3.62f2, сборка WebGL под Yandex Games. Портрет 9:16.
  - Рендер: Built-in render pipeline (без URP/HDRP) — самый простой,
    стандартные спрайты/шейдеры, меньше веса билда.
  - Физический движок НЕ используем: кинематическое движение, собственная
    инерция, отскоки от стен — расчёт вручную. Все пересечения (пуля-цель,
    пуля-пуля, зона парирования, подбор баффа, LOS-конус ИИ) — оверлап-
    проверки (дистанция/радиус) в коде, с гибко настраиваемым временем
    скана. Для быстрых пуль — swept-тест «отрезок vs круг» против
    туннелирования.
  - DI-контейнер: VContainer — composition root, связывание сервисов
    (экономика, конфиги, аудио, реклама, сейвы, спавнер).
  - Асинхронность: UniTask — таймеры КД, реген патронов, баффы, рекламные
    флоу (без корутин, zero-allocation для WebGL).
  - Архитектура: SOLID, чистое разделение — данные (ScriptableObject-
    конфиги) / логика (пейн-классы сервисов) / презентация (MonoBehaviour-
    вью). Полная оптимизация: пули — пул объектов, никакого GC в бою.
  - Интеграция Yandex Games SDK: rewarded-реклама (возрождение),
    interstitial (переходы уровней), сохранение прогресса (деньги,
    покупки, экипировка, максимальный уровень) через Cloud Saves /
    localStorage.
  - СЕЙВ-КАДАНС: сохранение на СТАРТЕ КАЖДОЙ ДУЭЛИ (уровень, деньги,
    экипировка). Перезагрузка страницы в бою → продолжение с текущего
    уровня, оружие и деньги при игроке.
  - Мультяшный 2D-арт: спрайты оружия по стадиям повреждения,
    анимации флипа/отдачи, партиклы.
  - Локализация RU/EN/TR: авто по локали + ручной выбор в настройках.
  - Управление мышь+тач из одной кодовой базы.
